# دليل الإغلاق: قبل الإصلاح وبعده

كل صف حالة واحدة نُفّذت حرفيًا على محاكي Firestore معزول (`swm-security-test`) مرتين: مرة بقواعد الإصلاح السابق (`before.json`) ومرة بالقواعد الجديدة (`after.json`). الملف المنفِّذ: `tests/rules/security.rules.test.mjs`.

| المؤشر | العدد |
|---|---|
| محاولات غير مصرح بها (deny) | 68 |
| كانت **مسموحة** قبل الإصلاح وأصبحت **مرفوضة** | 50 |
| كانت مرفوضة قبل الإصلاح وبقيت مرفوضة (تحصين) | 18 |
| غير مصرح بها وما زالت مسموحة بعد الإصلاح | 0 |
| عمليات مصرح بها (allow) ما زالت تعمل بعد الإصلاح | 41 من 41 |
