- **إنتاج:** Vercel + Firestore الفعلي.

## الخلاصة
- **محليًا:** 11 PASS، 3 PARTIAL، 1 NOT_TESTED. العرض ممكن على جهاز المطوّر بشرط تشغيل المحاكي والعامل أو الأحداث، وبحساب الأمانة مفتوحًا لقيادة نبضات المحاكي.
- **الإنتاج:** 15 FAIL، لأن الإصدارات بعد `8ce8886` غير منشورة. لم يمكن التحقق من نشر Vercel مباشرة (طلب API رُفض بـ 403)، فالحكم مبني على `git status: ahead 4`، والدفع إلى `main` هو آلية النشر.
- **قبل أي عرض عام يلزم:** إصلاح SEC-01 على الأقل (تصعيد الصلاحيات)، لأن حسابات العرض للموظفين قادرة على ترقية نفسها.

## مخاطر يوم العرض
1. **OSRM العام:** قد يبطئ أو يرفض، فيسند المحرك بتقدير موسوم (مختبر)، لكن رسالة «تعذر الاتصال» تظهر أمام اللجنة.
2. **المحاكي:** يتوقف إن أُغلق تبويب الأمانة القائد.
3. **قراءة التفريغ:** لا تظهر في لوحة البلدية إلا بعد نبضة المحاكي.
4. **الدورة الدورية المحلية:** تحتاج تشغيل `npm run dispatch:worker` يدويًا.
